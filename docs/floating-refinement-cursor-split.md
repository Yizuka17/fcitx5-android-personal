# 悬浮缩放、触感与独立光标（2026-10-30）

本次更新延续 `bottom-bar-selection-floating.md` 的底栏选择手势，并替换其菜单样式和预编辑处理。

## 行为

- 底栏轻击恢复输入法的按下触感，遵守关闭、跟随系统和自定义振动设置。
- 最小悬浮工具栏的内部图标按旧版实际绘制尺寸放大到 150%，上限为普通工具栏图标尺寸；Flexbox 压缩单元格时重新测量。
- 底栏高度、左右图标和手势菜单随悬浮尺寸缩放。菜单只有四个圆形图标，分别为复制、粘贴、剪切、全选。
- 底栏菜单与长按按键菜单共用圆形图标组件，避免背景内边距覆盖图标留白。按键图标直接设置缩放后的尺寸，文字弹窗直接设置字号，避免二次缩放导致裁切。
- 外侧拖动横条和缩放弧线加粗到 5dp；缩放弧缩短到 60°。二者到键盘本体的中心线间距仍为 12dp。
- 选择文本前不再顺带提交未选中的拼音候选。

## 拼音与文本光标分离（实验性）

设置位于“虚拟键盘”中“滑动底栏移动光标”下方，应用默认关闭；启用时需同时开启底栏移动光标。空格手势另需开启“滑动空格键移动光标”。

开启后，空格滑动只控制拼音缓冲区的光标；底栏滑动只控制编辑框的文本光标。移动文本光标时保留拼音内容、拼音光标和候选，选词后才把结果插入新的文本位置。没有待编辑拼音时，空格滑动不会移动文本光标。

实现会把编辑框中的临时 composing span 与原生拼音引擎分离，原生拼音缓冲区和 caret 保持不变，避免 Android 的 selection 更新重置拼音状态。
