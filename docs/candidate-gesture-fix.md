# 候选栏滑动修复（2026-10-26）

## 问题与修改

在 Xiaomi 15 Pro（Android 16 / HyperOS 3）上输入 `nihao`，旧版候选栏连续横滑仍停在原位置。
原横向候选栏使用 `FlexboxLayoutManager` 的单行布局并强制声明可横向滚动。
现在改用 `LinearLayoutManager` 管理单行滚动、惯性和视图回收；保留“不填充 / 自动填充 / 始终填充”的宽度设置。
少量候选可以均分剩余宽度；候选溢出时保留文字自然宽度，不压缩文字。

关闭横向列表的边缘拉伸，避免手指不松开转向下滑时，拉伸效果跟随手指位置变化。
候选项移动超过系统触摸阈值后取消按压高亮、点击和待触发的长按；单纯点击、静止长按仍保留原功能。
此手势配置只作用于横向候选项。

- 33 项 JVM 测试通过，Debug / Release 构建和 lint 通过；Release lint 为 0 错误、28 项警告。

  连续双向拖动，横滑后转下滑时位置不变，竖向拖动取消点击后可再次正常点击，
  少量候选填充及追加 / 改变宽度后的滚动；同时检查加载更多候选不会重置滚动位置。
- 2026-10-26 21:47 覆盖安装正式签名 ARM64 Release，签名证书与原版一致。
- Release 实机拼音输入首滑生效；继续进行多次左右往返滑动，没有再次卡住。
- 使用连续 DOWN / MOVE / UP 事件测试横滑后保持按住，再向下移出候选栏；
  下滑前后候选区域（1440 × 135 像素）完全一致，输入框保持为空，没有误选。

- 测试文字已清空，保留原拼音、主题与开关设置，并收起键盘。
