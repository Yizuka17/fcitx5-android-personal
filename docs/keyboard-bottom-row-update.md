# 键盘底行与底栏滑动更新（2026-10-25）

## 底行布局

文字键盘、手写键盘和主题预览共用 `BottomRowKeyboard`，统一语言键显隐、表情替代键和快捷动作。
原来手写键盘仅复用按键列表，没有监听语言键设置；现在关闭语言键会同时收回它占用的宽度。

“显示表情符号键”位于虚拟键盘设置，默认关闭，只有关闭“显示语言切换键”后才能开启。
以下变化仅在表情替代键实际启用时生效：

- 原语言键位置显示表情键，短按直接进入表情页。
- 逗号键上方图标变为 `#`；长按菜单首项也变为 `#`，直接进入符号页；短按仍输入逗号。
- `?123` 直接进入九宫格数字键盘。

关闭表情键或重新开启语言键后，恢复原逗号长按菜单和 `?123` 布局选择行为。
手写模式从数字、符号、表情页返回时仍回到手写；符号页中的数字入口也能正常打开数字键盘。

## 底栏滑动

“划动底栏以移动光标”独立开关默认开启，紧接在“划动空格键以移动光标”下面。
底栏可见时，中间空白区域支持连续向左、向右移动光标；两侧按钮保留原点击和长按行为。
空格键与底栏复用 `configureCursorSwipe`：每 10dp 一步，沿用方向键动作、重复触觉反馈设置和取消手势处理。
关闭该选项立即停用中间手势；它与空格键的开关相互独立。
主题预览不发送光标动作，悬浮模式仍按既有规则隐藏整个底栏。
