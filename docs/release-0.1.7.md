# Fcitx17 0.1.7

修复实验性光标分离下，文本光标到达最左后继续滑动，在部分编辑框中失去焦点、底栏手势与反馈随之停止的问题。

分离模式此前直接发送 DPAD 左右键。未开启分离时，原来的虚拟方向键经过 Fcitx 后由输入法使用 `setSelection` 处理。新实现让分离模式直接定位文本光标，避免把边界方向键交给宿主应用作焦点导航。

- 左边界为零时停止移动；右侧没有文本时停止移动。
- 接受位置后更新预测光标，连续滑动不依赖编辑框及时回报每一步选区更新。
- 收起已有选区时使用其相应端点，跨越普通 emoji 时不拆开 UTF-16 代理对。
- 编辑框拒绝定位、文本上下文暂不可用时，不退回发送可能导致焦点逃逸的方向键。
- 保留原来的拼音缓冲区、拼音光标及非分离路径。

Android 16 虚拟机通过 6 项针对性检查，使用实际 EditText/InputConnection 并模拟边界方向键触发焦点跳转的宿主行为；覆盖左右越界、反向移动、延迟选区回报、空文本、选区、emoji、定位失败，以及越界后持续滑动的触感调用。未在微信、DeepSeek 应用本体中复测。

ARM64 versionCode 为 162，使用原正式签名。
