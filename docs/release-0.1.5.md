# Fcitx17 0.1.5

- 修复 0.1.4 中候选栏左侧清空图标过大且缩放无效的回归：移除旧内边距的放大补偿，恢复 14dp 基准图标，并跟随工具栏缩放。
- 放大最小悬浮工具栏图标，取消依赖 Flexbox 测量宽度的旧补偿。图标尺寸随键盘宽度连续变化，避免缩放时先放大、回缩和过早保持不变。
- 更多等页面的返回、设置图标使用 32dp 基准并同步缩放，标题文字按实际字号测量。
- 修复最小悬浮“输入法设置”等标签裁切：按缩放字号重新布局、限制文字在单元格内，并为大系统字体保留足够的行高。
- 候选文字、两侧边距及最小宽度随悬浮尺寸缩小；缩小模式不再把少量候选拉宽填满候选栏，保留正常模式的填充偏好。
- 拖拽横条新增双击退出悬浮。拖动、长按或取消的触摸不会作为双击，原悬浮模式偏好保持不变。
- 底栏上划菜单新增第五项“剪贴板”，复用输入法剪贴板面板。菜单宽度按五个项目计算，并继续随悬浮尺寸缩放。

Android 16 虚拟机通过 25 项 Android 测试，覆盖候选清空图标缩放、连续调整图标尺寸、更多页面标签、大字体、候选实际占位、横条双击与误触取消，以及原候选/底栏手势回归。
ARM64 versionCode 增加至 142，沿用 Fcitx17 正式签名。
