# Fcitx17 0.1.4

本版本汇总 0.1.3 发布后完成的底部按键、候选滑动、悬浮底栏和独立光标改进。

## 交互改进

- 手写键盘与普通键盘同步语言切换键设置。关闭语言切换键后，可开启独立表情键；仅在该选项开启时，逗号长按首项改为符号页，`?123` 默认进入九宫格数字键盘。
- 修复候选栏横滑偶发卡住，以及横滑后不松手下滑导致候选抖动或误选。
- 底栏中间支持滑动移动光标；轻击后快速按住横滑可选择文本，继续上滑打开复制、粘贴、剪切、全选菜单。
- 悬浮键盘始终带有底栏；拖动横条和缩放弧线位于键盘外侧，采用一致间距和亮强调色。
- 最小悬浮工具栏图标放大，底栏与圆形图标菜单随悬浮尺寸缩放，恢复底栏轻击触感。
- 修正按键、长按菜单和 `?123` 的缩小显示。文字按实际缩放字号测量，避免先裁切再缩放。
- `?123` 与回车长按仅打开单手模式图标，上划进入图标后松手才执行；原地松手、退回按键或下滑均取消，而且不会触发普通按键。

## 实验性独立光标

“拼音与文本光标分离（实验性）”位于“滑动底栏移动光标”下方，默认关闭。
启用该功能与对应滑动设置后，空格只移动拼音光标，底栏只移动文本光标，互不改变。
未完成的拼音和候选保持待选，选词后插入移动后的文本位置；选择文本也不会顺带提交拼音候选。

## 验证记录

- 33 项 JVM 单元测试通过。
- 小米 Android 16 通过 21 项 Android 测试，含单手菜单上划与取消、取消时不落入普通点击、最小尺寸文字与图标、候选连续滑动、底栏触感和选区手势。
- 独立光标曾以正式签名包实机验证：`aaaaaaaa` 中间插入保持待选的 `nihao`，选词后得到 `aaaa你好aaaa`。
- ARM64 版本使用原正式证书签名；包名仍为 `org.fcitx.fcitx17.android`，versionCode 增加至 `132`。

其余实现与阶段验证详见 `keyboard-bottom-row-update.md`、`candidate-gesture-fix.md`、`bottom-bar-selection-floating.md` 和 `floating-refinement-cursor-split.md`。
