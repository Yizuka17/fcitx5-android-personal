# 输入法底栏与候选栏更新

## 实机依据

2026-10-24 检查连接的 Xiaomi 15 Pro（2410DPN6CC），Android 16 / HyperOS 3。
设备开启全面屏手势（navigation_mode=2、force_fsg_nav_bar=1），隐藏提示线（hide_gesture_line=1）。
在系统设置的搜索框中显示 Fcitx17，实际画面没有底部系统收起键和输入法切换键。
系统报告 mImeDrawsImeNavBar=false、mNavigationBarFrame=null。

## 行为与布局

目标：缺少系统导航按钮时，用户仍能直接收起键盘、切换输入法或语言。
保持当前主题色、工具栏按钮、按压反馈，不新增视觉风格和过渡动画。

- 主题设置新增“键盘底栏”：自动识别（默认）、开启底栏、关闭底栏。
- 默认左侧收起键盘、右侧切换语言；左右可分别选切换输入法、语言、剪贴板、符号、表情、无。
- 切换语言在 Fcitx 已启用的输入法间循环；切换输入法切到下一个系统输入法应用。
- 两种切换键都支持长按打开系统输入法选择器。
- 自动识别查看本输入法窗口中可见的系统导航视图、IME caption inset、三键导航边距；
  不把单独的手势区域当成已有导航按钮，也不按手机品牌硬编码。
- 系统自绘导航不可被普通输入法完整查询，提供手动覆盖处理 OEM 差异。
- 底栏高 44dp，两侧触摸区域宽 56dp；系统安全边距另行保留；悬浮模式隐藏底栏。
- 单手模式下，候选栏和预编辑栏与键盘主体采用相同宽度和左右对齐；底栏也跟随主体。
- 悬浮/单手面板的背景从候选栏开始绘制；拼音预编辑仅在文字范围保留自身衬底，空白区域透明。
- 主题页和自定义主题页的键盘预览复用底栏组件，响应显隐模式、左右动作图标和主题色变化；
  与原有预览键盘一致，只预览配置，不在设置页执行实际输入法动作。
- 候选条改为单行横向滚动，接近末尾时按批从引擎取后续候选；输入改变时取消旧请求。
- 符号、表情和颜文字保留缓存视图，但在加入可见布局前停止滚动、刷新最近使用并跳到第一页。
